# RUL-008 Network rule-space adapter

A frozen stochastic binary-state network substrate for Entropy Studio Ruliology experiments.

The local update rule is parameterized by activation threshold, neighbor coupling, node memory, and stochastic temperature. The same rule coordinates are evaluated on three fixed topology blocks: ring lattice, small-world, and matched-degree Erdos-Renyi.

Topology is **not** silently folded into the rule metric in RUL-008. It is a blocked environmental/interaction-structure factor. Aggregate rule profiles average over the preregistered topology blocks, while topology-specific profiles are retained for audit.
