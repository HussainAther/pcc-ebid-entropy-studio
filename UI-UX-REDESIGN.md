# Entropy Studio UI/UX Redesign

This release reorganizes Entropy Studio around the actual research workflow instead of the implementation history.

## Navigation

The sidebar is grouped into four stable areas:

- Research: dashboard, corpus, hypotheses, experiments, campaigns, and runs
- Analysis: observables, statistics, figures, and evidence graph
- Publication: manuscripts, datasets, and critical review
- Infrastructure: repositories and engines

## Interface improvements

- Persistent page context and loaded-run count
- Clearer active-navigation states and workflow labels
- Modernized typography, spacing, panels, buttons, and status elements
- Denser but more legible research tables and cards
- Responsive laptop, tablet, and narrow-screen layouts
- Stronger hover, empty-state, and disabled-state differentiation
- Existing provenance and epistemic-status language remains visible

## Scientific behavior

No experiment, statistical, evidence, publication, or package-generation rules were weakened. The redesign changes navigation and presentation while retaining the existing data model and execution boundaries.
